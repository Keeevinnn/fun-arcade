# 趣玩街机 Fun Arcade 🕹️

复古街机霓虹风的小游戏合集，纯前端实现，打开即玩，电脑 / 手机都支持。

## 快速开始

直接双击 `index.html` 用浏览器打开即可，无需安装、无需联网。

## 游戏列表

| 游戏 | 玩法 |
| --- | --- |
| 🐍 贪吃蛇 | 吃掉能量方块让自己变长，速度会越来越快，别撞到墙和自己 |
| 🔢 2048 | 滑动方块，让相同数字相撞合并，目标是拼出 2048 |
| 🧱 打砖块 | 移动挡板接住小球，把上方的砖块全部击碎即可过关 |
| 🃏 记忆翻牌 | 翻开卡片找出相同图案，用最少的步数完成配对，关卡越往后越多 |
| ⚡ 反应力测试 | 屏幕变绿的瞬间立刻点击，测测你的反应速度有多快 |

## 操作方式

- **电脑**：键盘方向键 / WASD，或鼠标操作
- **手机**：触摸滑动 / 点按

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无任何第三方库与构建工具
- 单入口 `index.html` + 各游戏独立 JS 模块
- 最高分使用浏览器 `localStorage` 本地存储
- 支持响应式布局与触屏手势（Pointer Events）

## 项目结构

```
fun-arcade/
├── index.html      # 唯一入口，加载样式与各游戏脚本
├── styles.css      # 全局样式：霓虹配色、像素字体、CRT 扫描线
├── arcade.js       # 主控：大厅渲染、路由、游戏生命周期、最高分存储
├── snake.js        # 贪吃蛇
├── game2048.js     # 2048
├── breakout.js     # 打砖块
├── memory.js       # 记忆翻牌
└── reaction.js     # 反应力测试
```
